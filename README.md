# FreshBasket storefront
An original React + TypeScript grocery e-commerce starter inspired by modern fresh-food shopping experiences. It does not copy proprietary branding or source code.

## Run
```bash
npm install
npm run dev
```

## Production checklist
- Replace mock products with a database/API.
- Add server authentication and protected account routes.
- Connect Paystack, Flutterwave or another approved payment provider.
- Connect inventory, order, email/SMS and delivery services.
- Replace placeholder legal, business and contact text.
- Add admin product/order/customer management.
